# Паритет с вебом — статус iOS

Номера — из `PARITY.md` репозитория `rst-msg` (снимок: [server/PARITY.md](server/PARITY.md),
коммит 51b72f1). Статусы: `есть` / `частично: чего нет` / `нет` / `не нужно на iOS: почему`.

Обновлено 2026-10-19 после этапа A («читать всё, что присылают другие клиенты») и
большей части этапа B (возможности переписки). Всё собрано и проходит тесты в CI,
на телефоне ещё не проверено.
