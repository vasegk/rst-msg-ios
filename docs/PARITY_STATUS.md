# Паритет с вебом — статус iOS

Номера — из `PARITY.md` репозитория `rst-msg` (снимок: [server/PARITY.md](server/PARITY.md),
коммит 51b72f1). Статусы: `есть` / `частично: чего нет` / `нет` / `не нужно на iOS: почему`.

Обновлено 2026-10-19 после этапов A–D: чтение всего, что присылают другие клиенты;
возможности переписки; группы и каналы; профиль, настройки, общее. Всё собрано и
проходит тесты в CI, на телефоне ещё не проверено. Этап E: истории и звонки (кроме своего показа экрана и картинки в картинке).

## 9. Звонки
Входящие звонят, только пока приложение открыто: в фоне без VoIP-push (PushKit, нужен
аккаунт Apple Developer) iOS сокет не держит.

| № | Статус |
|---|---|
| 9.1 Аудио и видео один на один | есть (WebRTC, TURN из `/api/turn-credentials`, смена камеры, динамик) |
| 9.2 Показ экрана | частично: показ собеседника виден; свой показ — нет (на iOS нужен отдельный модуль ReplayKit) |
| 9.3 Групповые звонки | есть (сетка соединений, камера, микрофон, «Идёт звонок · Присоединиться»; показа экрана нет) |
| 9.4 Журнал звонков | есть (запись звонившим, «Настройки → Звонки»); пропущенный в переписке — как пришлёт сервер |
| 9.5 Отказ микрофона/камеры | есть (объяснение «Разрешите в Настройках → RST») |
| 9.6 Свернуть звонок | есть (плашка «Имя · время · Вернуться / Завершить», сетка по свободному месту) |
| 9.7 Картинка в картинке | нет |
