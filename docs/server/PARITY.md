# Паритет веба и Android

Опись всего, что умеет веб-клиент, — эталон для Android-приложения. Ведёт
веб-часть: каждая новая возможность веба попадает сюда в той же правке.
Android-часть сверяет приложение с этим списком и отмечает статус у себя,
в `rst-msg-android/docs/PARITY_STATUS.md` (по номерам отсюда):
`есть` / `частично: чего нет` / `нет` / `не нужно на Android: почему`.

Подробности поведения (пороги, размеры, тексты) — в коде по указанному файлу и
в записях `HANDOFF_FROM_SERVER.md`; протокол — `PROMPT_ANDROID.md`.

Составлено 2026-10-02 по коду веба на коммите 3a2fcf1.
