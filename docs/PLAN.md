# RST для iOS — план

Совместимость с вебом и Android важнее любых улучшений. Решения по протоколу —
как в Android-клиенте (`rst-msg-android/docs/PLAN.md`).

## Решения

- **SwiftUI + Observation, iOS 17+.** `@Observable` модели на главном акторе;
  тяжёлое (PBKDF2, расшифровка файлов) — в `Task.detached`.
- **Криптография — CryptoKit и CommonCrypto.** ECDH: `sharedSecretFromKeyAgreement`
  отдаёт ровно координату X, как `deriveKey` в WebCrypto. AES-GCM: тег в конце
  шифротекста, как в WebCrypto. PBKDF2 — `CCKeyDerivationPBKDF`, пароль в UTF-8.
- **Секреты — связка ключей** (`AfterFirstUnlockThisDeviceOnly`): токен, KEK,
  приватный JWK. Отпечатки ключей собеседников и список «защищённых» групп —
  в UserDefaults (они не секретны, как localStorage в вебе).
- **Проект — XcodeGen**, сборка и тесты — GitHub Actions на macOS.
- **Без сторонних зависимостей** на первом этапе.

## Этапы

1. **Ядро** *(сделано)* — крипто-ядро с тестами на эталонах WebCrypto, вход,
   регистрация, восстановление, список чатов, переписка, вложения, голосовые,
   опросы, группы и каналы, профиль, приватность, сеансы.
2. **Push** — APNs + Notification Service Extension (расшифровка на устройстве).
   Нужен Apple Developer аккаунт и правка сервера (см. HANDOFF_ENTRY.md).
3. **Переписка, догнать веб** — поиск по сообщениям (копия на устройстве),
   отложенные, выделение и пакетная пересылка, «Кто прочитал», превью ссылок,
   кружки, местоположение, стикеры и мастерская, темы групп, комментарии каналов.
4. **Истории.**
5. **Звонки** — WebRTC (сигнализация `rtc_signaling`, TURN из `/api/turn-credentials`),
   CallKit + PushKit.
6. **Несколько аккаунтов, обои, экспорт, данные и память.**
